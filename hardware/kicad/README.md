# KiCad design area

**STATUS: conceptual, not electrically verified or manufacturing-ready.**

Earlier v0.1 starter KiCad files were only design placeholders, not reliable engineering files. They must not be treated as validated production designs.

Before fabrication, verify connector footprint and pad count; physical pitch and orientation; mapping from visible solder pads to real socket contacts; power voltage/current/sequence; PCIe lane pairs and reference clock; reset and management sidebands; PCIe impedance/stackup; and ERC/DRC results.

Publish original CAD only when it accurately reflects verified measurements; preserve the version and known limitations in each release.
